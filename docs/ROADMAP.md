# Roadmap

AI Portfolio Builder is currently an early-stage project. The roadmap is a
direction, not a release commitment, and will evolve through contributor
feedback.

## Phase 1 - Project Foundation

- [x] Clean project README
- [x] Add an open source license and third-party notices
- [x] Add basic product and architecture documentation
- [x] Add contribution guidelines
- [x] Add GitHub issue templates

## Phase 2 - MVP

- [ ] Add CV upload for PDF and DOCX
- [ ] Add LinkedIn URL input or user-authorized profile import
- [ ] Add AI extraction of profile data
- [ ] Define and validate a portfolio data model
- [ ] Generate a static portfolio from structured data

## Phase 3 - Editing Experience

- [ ] Make generated sections editable
- [ ] Add theme selection
- [ ] Add preview mode
- [ ] Add export and deployment options

## Phase 4 - AI Agent Workflow

- [ ] Improve extraction accuracy and source traceability
- [ ] Add personalization prompts
- [ ] Generate portfolio recommendations
- [ ] Add content quality and completeness checks

## Phase 5 - Open Source Maturity

- [ ] Add automated tests
- [ ] Add continuous integration
- [x] Add issue templates
- [x] Add a contribution guide
- [ ] Define a release process
- [ ] Publish versioned releases

## Guiding Principles

- Keep users in control of generated content.
- Clearly identify AI-generated or inferred information.
- Minimize collection and retention of personal data.
- Preserve a simple local development experience.
- Build reusable components without over-engineering the MVP.
